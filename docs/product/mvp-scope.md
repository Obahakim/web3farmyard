# MVP Scope Guardrails

This foundation intentionally does not build feature pages, the Commons, Sleepagotchi integration, or mobile apps.

Allowed next features:

- Emotional Vault CRUD using encrypted `VaultEntry` rows.
- Audio Dumps using `AudioDump`, object storage, and transcription jobs.
- AI Companion using `@deepn/ai` provider abstraction.
- Locked Vault client encryption flow.
- Emotional Timeline worker jobs.

Deferred features:

- Commons UI and moderation workflows.
- Sleepagotchi import and correlation engine.
- Native mobile apps.
- On-chain credentials.
- Self-hosted AI runtime.
